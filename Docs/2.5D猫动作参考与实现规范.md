# 团团 2.5D 动作参考与实现规范

## 结论

本项目保持 2.5D 路线，不使用完整 3D 骨架，也不把其他猫的外观加入团团素材。
网络素材只用于学习关键点轨迹、落爪顺序、重心移动和动作过渡。

## 推荐参考资源

### 1. 猫行走生物力学

- 论文：https://pmc.ncbi.nlm.nih.gov/articles/PMC4044364/
- 成年猫普通行走采用 lateral-sequence 四拍步态。
- 接触顺序：右后爪 RH → 右前爪 RF → 左后爪 LH → 左前爪 LF。
- 一个完整周期包含 8 个支撑阶段。
- 常见支撑数量变化为 3 → 4 → 3 → 2 → 3 → 4 → 3 → 2。
- 加速时主要缩短 stance（支撑）阶段，swing（摆动）阶段变化较小。

### 2. AP-10K 单帧动物关键点

- 官方仓库：https://github.com/AlexTheBad/AP-10K
- 许可：CC BY 4.0。
- 10,015 张图片、54 个物种、17 个关键点。
- 适合建立 Stand/Sit/Lie/Sleep Base Pose 和检测明显反关节。
- 不包含连续时间信息，不应单独用于学习走路节奏。

关键点采用：眼、鼻、颈、尾根、左右肩、肘、前爪、髋、膝、后爪。
团团是长毛猫，肩髋常被毛遮挡，2.5D 实作优先锁定鼻、颈、尾根和四个 paw。

### 3. APTv2 / APT-36K 连续动物关键点

- 官方仓库：https://github.com/ViTAE-Transformer/APTv2
- APT-36K 仓库：https://github.com/pandorgan/APT-36K
- APTv2 含 2,749 个视频片段，每段采样 15 帧，共 41,235 帧。
- 适合学习 paw 轨迹、身体中心轨迹、动作速度和姿势过渡。
- 仅筛选 Felidae、单只动物、近侧面、无遮挡片段作为动作参考。

### 4. 慢动作视频索引

- https://motionzoo.net/cat-walk-reference/
- 页面整理了侧面、正面和慢动作猫行走视频及可用时间段。
- 使用时只人工观察动作规律，不复制视频画面进入发布包。

## 当前 32 帧 Walk Cycle 标准

| 帧 | 事件 | 根位移 | 说明 |
|---:|---|---:|---|
| 0 | RH 接触 | 0 | 右后爪落地，画面不得水平滑动 |
| 1–7 | RH 支撑/蹬地 | 逐渐增加 | 身体经过支撑爪，后段蹬地 |
| 8 | RF 接触 | 0 | 右前爪落地 |
| 9–15 | RF 支撑/蹬地 | 逐渐增加 | 前肩轻微下沉后恢复 |
| 16 | LH 接触 | 0 | 左后爪落地 |
| 17–23 | LH 支撑/蹬地 | 逐渐增加 | 与右侧镜像 |
| 24 | LF 接触 | 0 | 左前爪落地 |
| 25–31 | LF 支撑/蹬地 | 逐渐增加 | 回到循环起点 |

每个 8 帧阶段的根位移权重：

```text
0.00, 0.15, 0.65, 1.25, 1.75, 1.75, 1.45, 1.00
```

原则：Sprite 不换帧时根节点不得移动；落爪帧根位移必须为 0。

## Base Pose 架构

```text
Stand_Base
Sit_Base
Lie_Base
Sleep_Base
```

大姿势变化使用独立 Base Pose 素材和专用过渡序列；小动作才使用局部网格、平移、微旋转和缩放。

### Stand_Base 内部动作

- 呼吸：胸腹总缩放不超过约 1.5%。
- 眨眼：独立眼皮或替换帧。
- 耳动：小角度、非同步。
- 头部注视：平移 + 轻微旋转 + 眼球移动，不整张头大角度旋转。
- 尾巴：至少三段延迟摆动。
- Walk：四拍落爪与根位移同步。

### Sit_Base 内部动作

- 呼吸、眨眼、耳动、看鼠标。
- 舔爪、擦脸。
- 尾巴贴地的小幅摆动。

## 不采用的方案

- 不用 StanfordExtra 作为猫动作主数据：它是犬类数据集。
- 不把 YOLO 行为检测框当作动作骨架：检测框没有 paw/关节轨迹。
- 不直接下载来源和许可不明确的网盘数据进入项目。
- 不把 Unity 商店 3D 猫动作直接套到 2.5D 团团外形。
- 不训练新的外观模型；团团身份仍由用户照片和现有参考图锁定。

## 后续制作顺序

1. 从用户照片确定 Stand_Base 与 Sit_Base 主素材。
2. 分离最低可用图层并补全遮挡区域。
3. 为 Stand_Base 建立 32 帧四拍走路和小幅待机。
4. 为 Sit_Base 建立舔爪、擦脸、观察等局部动作。
5. 最后制作 Stand ↔ Sit 的专用过渡，不使用通用光流硬变形。

## v1.7 实现进度

- 运行时新增 `Stand / Sit / Lie / Sleep` 四种基础姿势语义；本轮完整接通 Stand 与 Sit。
- 站坐转换统一使用 `curious_groom_000..008`，反向复用同一序列，动作不再各自硬切回站姿。
- 打哈欠、舔爪和坐下观察先进入 `Sit_Base`，完成后再经过坐到站的过渡。
- 走路、闻嗅和挥爪会先确认处于 `Stand_Base`，防止从错误姿势直接起播。
- 新增站姿、坐姿 4×4 分层源图集；当前作为清边和拆层母版，暂不直接叠到运行时，避免未经人工清理的长毛边缘产生双影。
- 锚点、层级顺序、微动上限和过渡帧集中记录在 `Assets/PoseProfiles/base_poses.json`。

下一轮优先拆出并接入 `Head_Base + Ear_L/R + Eye_L/R`。头部组不改变落地线，适合先验证眨眼、耳动和视线跟随，同时不破坏已稳定的步态。

## v1.8 Face Layer Runtime

- FaceLayer 作为 BasePose 上方的独立叠加控制器，不增加“站着眨眼”等组合状态。
- Stand 与 Sit 使用各自照片衍生的虹膜底层、左右瞳孔、闭眼覆盖层和左右耳朵层。
- 瞳孔跟随鼠标时采用归一化目标和平滑追踪，水平限制 4 px、垂直限制 3 px。
- 自动眨眼间隔为 3.5–8 秒，15% 概率双眨眼；闭合和打开使用平滑曲线。
- 左右耳以耳根为 Pivot，5–12 秒随机 twitch，并叠加很小的鼠标方向偏转。
- 整帧动作播放时自动隐藏 FaceLayer，回到稳定 Stand/Sit 帧时恢复，避免动作帧与脸部覆盖层错位。
- Lie/Sleep 沿用原有闭眼整帧；Sleep 不启用鼠标视线，只保留原睡眠呼吸。
- 所有可调范围位于 `Assets/FaceLayers/face_runtime.json`，锚点位于 `face_layers.json`。

## v1.9 Head / Neck Rig

- Stand 与 Sit 各自新增 `Body_Base / Head_Base / Neck_Fur / Chest_Fur` 四层。
- `Body_Base` 已移除旧头轮廓，并使用照片风格补全素材重建原先被头遮挡的脖颈与肩部毛发。
- `Head_Base`、眼睛、瞳孔、闭眼层和左右耳全部归入同一个 HeadGroup，围绕脖颈连接点统一平移和旋转。
- `Neck_Fur` 与 `Chest_Fur` 保持在 HeadGroup 前景，利用长毛覆盖头身接缝。
- Stand 头部 Pivot 为 `(401, 278)`，Sit 为 `(372, 286)`，均位于脖颈连接处而不是头部中心。
- 头部跟随限制为水平约 ±3.2 px、垂直约 ±1.8 px、旋转约 ±3°，使用独立平滑速度。
- 大动作与过渡帧继续使用完整整帧素材，HeadRig 自动关闭；只在稳定 Stand/Sit Base 帧启用。
- HeadRig 素材和遮挡范围记录在 `Assets/HeadRig/head_rig.json`，可重新运行 `Tools/prepare_head_rig.py` 非破坏性生成。

### v1.9.1 眼头耦合修复

- 左右瞳孔各自增加固定在 HeadGroup 内的椭圆眼眶裁剪区，瞳孔平移不能越出眼眶。
- 视线目标改为从运行时真实眼睛屏幕坐标计算，并包含当前头部偏移，不再使用窗口比例估算头中心。
- 瞳孔相对位移收紧至水平约 ±2.6 px、垂直约 ±1.8 px。
- 头部偏移收紧至水平约 ±2.6 px、垂直约 ±1.4 px、旋转约 ±2.2°。
- 眼睛、闭眼层和耳朵仍全部位于 HeadGroup 内，先继承头部变换，再执行各自的小范围局部变换。

### v1.9.2 坐姿完整头层修复

- 原坐姿 `Neck_Fur / Chest_Fur` 蒙版顶部覆盖到下巴和下半张脸，造成上半头随 HeadGroup 移动、下半头被静态前景层压住。

- Sit `Chest_Fur` 下移至胸口区域，不再覆盖脸颊与下巴。
- Stand 同步收紧前景遮挡范围，避免相同问题在较大头部偏移时出现。

### v1.9.3 头颈预留重叠区

- 头和身体不能边对边拼接；`Head_Base` 必须带一圈不会在静止画面中直接看见的隐藏鬃毛。
- 身体上的旧头清除槽改为小于 Head_Base：头层横纵范围扩大，Body Clear Mask 相应缩小。
- 头层与身体底图在头颈连接处保留约十几像素重叠，即使平移 ±2.6 px、旋转 ±2.2°也不会直接露出桌面背景。
- `Neck_Fur / Chest_Fur` 继续位于前景，只负责柔化毛发接缝，不再承担填补透明洞的任务。
- 生成脚本新增最大位移/旋转压力预览：`stand_movement_preview.png` 与 `sit_movement_preview.png`。

## v1.10 Upper Body Follow

- Stand 与 Sit 从 Body_Base 中继续拆出 `UpperBody_Base`，覆盖肩部、后颈与上胸，但不包含落地爪和下半身。
- Lower Body 的肩胸透明槽小于 UpperBody 图层，保持与头颈相同的隐藏重叠策略。
- 运行时层级改为 `LowerBody → UpperBodyGroup → HeadGroup → Eyes/Ears`。
- 鼠标响应形成三级延迟链：瞳孔最快，头颈其次，肩胸最慢。
- UpperBody 最大位移约为水平 ±1.2 px、垂直 ±0.7 px、旋转 ±0.8°；头部仍保留更明显的局部跟随。
- UpperBody 以肩部下缘为 Pivot，前爪和下半身保持固定，因此不会破坏地面接触或重新产生滑步。
- 大动作与过渡帧依然切回完整整帧素材，UpperBody/Head 两级骨骼同时隐藏。

### v1.10.1 镜像朝向修复

- 猫向左移动后 `PetVisual.ScaleX = -1`，此前仍把屏幕右方向直接当作骨骼局部 +X，导致镜像状态下视线和身体跟随反向。
- 现在先计算鼠标相对实际 HeadGroup 屏幕位置的方向，再根据 `PetScale.ScaleX` 转换成局部骨骼方向。
- HeadGroup 的屏幕位置通过完整视觉变换链计算，包含镜像、Viewbox 缩放、UpperBody 与 Head 的当前偏移。
- 瞳孔、头颈、肩胸和耳朵共享修正后的局部方向；无论猫朝左还是朝右，最终屏幕运动都指向鼠标。

## v1.11 BodyLook Runtime 第一阶段

- 所有运行时输入统一为 `EyeLookX/Y`、`HeadLookX/Y`、`ChestLookX`、`BodyLookX`，范围均为 `-1..+1`。
- MouseX 使用鼠标与运行时 HeadGroup 眼睛中心的屏幕水平距离除以 360，并 Clamp 到 `-1..+1`；之后根据 `PetScale.ScaleX` 转换到骨骼局部方向。MouseY 使用垂直距离除以 280。
- `|MouseX| < 0.30`：仅 EyeLook；`0.30..0.65`：增加 HeadLook 与 EarLook；`>= 0.65`：再增加 ChestLook 与 BodyLook。
- Eye smoothing 为 0.20；Head 为 0.10；Chest 为 0.055；Body 为 0.025。数值为每个 16ms Tick 的指数趋近系数。
- Head 最大输出扩大为 X ±10 px、Y ±5 px、旋转 ±7°；素材压力预览同步按此最大值验证。
- Chest 只使用 X ±2 px、Y ±0.8 px 与 ±1.2° Skew，不使用 Body sprite Z rotation。
- BodyTurn 状态为 `Left3Q / Center / Right3Q`，进入侧姿阈值 0.65、返回 Center 阈值 0.40，附加随机 300–600ms 方向停留确认。
- 状态机禁止 `Left3Q ↔ Right3Q` 直跳，必须经过 Center。
- 当前只有 Center 资源标记为 available；侧姿状态可以逻辑触发，但渲染保持 Center，直至真实分层素材接入。
- DirectionPose 资源接口位于 `Assets/DirectionPoses/direction_poses.json`，所需图层见同目录 README。
